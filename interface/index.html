Somente seleção

Clique em um campo colorido e selecione na descrição o trecho correspondente.

Atalhos: use as teclas 1 a 8 da fileira superior ou do teclado numérico para selecionar os campos de extração. A tecla 1 abre exclusivamente a lista de Categoria. Depois de pressionar 1, digite letras para filtrar as categorias; o filtro é limpo ao trocar de dado. Pressione 9 e selecione um trecho da descrição para pesquisá-lo; pressione 9 novamente para cancelar. Pressione novamente o número do campo ativo para desmarcá-lo. Clique novamente no campo ativo ou pressione Esc para desmarcá-lo. O Enter principal ou numérico avança para o próximo dado. O botão direito abre as opções de restaurar e limpar o campo.
